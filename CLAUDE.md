# LanguageGenerator

## Documentation

- [docs/phonology.md](docs/phonology.md) and [docs/grammar.md](docs/grammar.md) describe in full what each generation stage does. A feature PR updates the section it belongs to, adding a subsection where none fits.
- The README's "How a language is generated" keeps one short bullet per stage, linking into those docs. Change a bullet only when what it summarizes changes, like a new stage or a new kind of choice, not for each feature within a stage.
- New grammar that real text still needs goes in [docs/roadmap.md](docs/roadmap.md) until it's built, then moves into the docs above.
